## Explicit refinements, not silent requirement changes

**Existing integration is retained.** `/` already renders GlyphokuStudio. The revised task repairs enforcement rather than assembling a duplicate desk.

**Action allocation is made enforceable.** The source describes domain first, envelope second, within a two-issuance horizon. The revised profile reserves g=1 for that domain and g=2 for its envelope. The baseline's extra-domain possibility is treated as an incompatible branch, not a reason to increase HORIZON_G. Already-existing incompatible data are preserved read-only.

**Timing is clarified.** Default 24x remains 24 logical events per 100 ms; it is not a promise of one visible DOM paint per event or fixed wall-clock duration. The original measured sample remains historical and unverified here. New phase-specific observations are required.

**Budget semantics are explicit.** Per-board total event caps include INIT and terminal events; no cap+1 success is permitted. Preparation limits must be selected and recorded before a run; the original four-attempt strategy is not treated as a complete time/memory bound. No band or horizon is weakened.

**Existing-operation retrieval is separate from issuance.** Original W05 promises repeat retrieval; baseline code checks the horizon before its lookup. The new read-only idempotent path preserves that promise without creating another resource at g=3.

**Negative tests use valid preconditions.** Original W07's post-send instance is not sufficient for g=1/g=2 validator tests. The revised matrix records each expected validator and tests it before the horizon can mask the defect.

**Preservation replaces silent recovery-to-empty.** The original says bad JSON is quarantined. The actual loader does not quarantine parse errors and may overwrite empty state later. The revised contract preserves bytes and blocks mutation; it does not claim to have repaired them already.

**Browser scope is qualified.** Local registry operations are not SMTP and do not perform mailbox DNS/MX resolution. The app's HTTP server and active scaffolding must be evaluated separately; wildcard development hosting is not loopback-only. Browser persistence and hashes are not server-grade durability or hostile-owner tamper resistance.

**Source status is unchanged.** The 4,800 count is inherited from the supplied material, not a new per-item inventory. All source assessments remain NOT_ASSESSED. These 72 authored local cases are separate and initially NOT_RUN. The 14 BEM parent ZIPs, twelve Glyphoku parent ZIPs and other nested attachments remain unexpanded and unexecuted by this tailoring work.
