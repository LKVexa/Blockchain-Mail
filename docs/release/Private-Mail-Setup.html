Workspace391 private mail

One application includes the mailbox, private mail server and Tor connection. Once computers belong to the same private network, sending to another computer works like sending any email: choose New message, enter its assigned @127 address, write your message, attach files, and press Send. The application chooses the route automatically.

Open your mailbox

  1. Extract W391.zip into its own folder under D:\Codex. Open its W391 folder and double-click Open Workspace.vbs. It prepares the application on first opening.
  2. Create your vault and save its recovery words privately. If you already have a protected workspace, unlock it with its original recovery words.
  3. Open your mailbox. Tor and the first private network start automatically. Login assigns your account an available @127 address, shown beside your mailbox.

The package includes its Tor runtime. Normal startup needs no separate Tor installation or port selection. Existing networks, accounts and mail history are preserved.

Add another computer once

  1. On the first computer, open Settings → Connected computers → Connect another computer. Choose Copy connection code.
  2. Open the same application on the other computer, with its own vault and recovery words. Open Settings → Connected computers.
  3. Paste the code into Connection code from the first computer and choose Connect this computer. The application completes registration, assigns the computer's address range and updates its signed directory.
This one-time pairing tells the application which private group to join. Each code connects one computer. Share it only with the intended computer and keep the first workspace open while it joins. No registration files need to be exchanged.

Connecting and refreshing the signed directory have no fixed waiting deadline. The application retries recoverable Tor reachability failures while it stays open. Close the workspace to stop waiting. Individual mail delivery attempts still have their own connection and transfer limits.

Distribute the fresh application package. Keep each computer's live state and network-state folders on that computer. Recovery words, mailbox access tokens and Tor secret keys stay private.

Send mail and files

Copy the complete assigned address displayed in the recipient's mailbox into New message. A new address looks like mail@127.0.0.2:10000000000000000002. There is one Send form for mail on your computer and mail to other connected computers. Ordinary mailbox sends are free: no credits, balance or credit allowance are needed.

The digits after the colon identify a private mailbox. They are not a network port, and you do not need to choose them. The application assigns 20-digit identifiers automatically; the format supports up to 32 digits. Each of the three numbers after 127 can be 0 through 255. Existing assigned addresses, including earlier rmail addresses, remain valid.

The signed computer directory maps the virtual host, such as 127.0.0.2, to that computer's Tor onion address and public keys. Tor carries the mail there, and the complete private identifier selects the account's own mailbox. The application handles this automatically when you press Send.

Each account sees only its own Inbox, Sent history and delivery attempts. Sent shows progress; Recipient mailbox received means the receiving computer saved the message and returned its signed receipt. Check send attempt checks that receipt without sending a duplicate.

Mailboxes have no fixed storage quota, and the normal attachment picker has no fixed file-size or total attachment byte limit. Available disk space is the practical limit for messages and files. Each message supports up to four files. Files transfer in encrypted chunks and received files save through the browser's file picker, so a complete file need not fit in memory. Mailbox exports contain attachment references; save the files separately. A private backup includes the encrypted attachment files.

Keep the computers available

The current private group supports up to 256 computers, with up to 64 accounts per computer. Its larger address format does not remove these current registration limits or the need for available storage.

Keep the first computer running for normal group use. It handles new registrations and directory updates, and forwards expanded routes when a direct neighboring route is unavailable. The receiving computer and any forwarding computers must also have Workspace391 running. Neighboring computers can exchange mail directly when both are running and already have the signed registrations.

Tor starts and stops with the workspace. This network exchanges private mail between assigned @127 mailboxes. Each computer remains an operator-controlled vault, with authenticated encryption between computers.
